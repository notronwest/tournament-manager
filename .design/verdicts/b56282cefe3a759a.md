## Notes (non-blocking)

- **The above-the-list confirmation has no owner and no way out.** It is
  dated, so it never lies, but it survives everything short of opening a row:
  typing `zzzqqq` leaves it sitting above *"No tournament matches "zzzqqq"."*,
  where it reads as an answer to the search the operator just typed
  (`390-tournaments-confirmation-persists-above-an-unrelated-empty-search.jpg`);
  a tab round trip brings it back; with the list emptied there is nothing
  left to toggle, so it stays until the page is left. A dismiss, or clearing
  it on a search change, would settle it.
- **The two confirmations of one action use different words (#10-adjacent).**
  The row says *"Saved just now — this fee applies to the next registration
  taken."*; the orphan says *"… now follows its organizer or the default."*
  and never names the fee that now applies. Which one an operator sees
  depends only on whether the row stayed in the list.
- **The orphan panel's pull can be spent on a keystroke.** Its key
  (`orphan-${at}`) is first consumed on the panel's first mount, and when a
  rate is *set* the row stays in the list, so that first mount happens later,
  on the search that hides the row. Read in the code at
  `PlatformSettingsPage.tsx:596–601`; **not reproduced in render** — the
  two-tournament fixture never makes the page long enough to show a jump.
- **The row-level panels lost their pull entirely.** `FeeRow`'s success and
  refusal (`PlatformSettingsPage.tsx:819`, `:826`) pass no `pullKey`, so they
  never move the page — previously they always did. Measured safe on this
  page: an open editor is ~387 px tall, so the row head is never more than
  that above the Save button and the panel lands in view (saved a row with
  its button at 756 → panel at 730–795). It is safe by a margin that nothing
  states, and a taller row editor would silently re-create the old defect.
- **The Default tab's refusal outlives the tab, too.** After a round trip to
  Tournaments and back, a refusal from minutes earlier re-mounted at
  **845–930** — undated, below the fold, and with nothing that clears it. The
  last verdict noted this for the confirmation; it is true of the refusal as
  well, and worse, because an unseen refusal reads as a save that worked.
- **`scrollMarginBlock: 56`** (`PlatformFeeEditor.tsx:377`) is off the
  4/8/12/16/24/32 scale (#5). It is a scroll margin, not visible spacing, and
  it is derived from a measurement — a nit, recorded because the number is in
  the file.
- **`pulled` grows for the life of the page** and is never pruned. A handful
  of short strings; not a design matter, named only so it is not mistaken for
  an oversight later.
- Every standing note from the third through sixth verdicts is unchanged by
