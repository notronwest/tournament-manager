## Notes (non-blocking)

- **The "by …" name is never refreshed after a save.** `savedByName` is fetched
  once on mount from the `updated_by` that was stored then
  (`PlatformSettingsPage.tsx:213–223`), and a save replaces `settings` without
  touching it (`:277`). So if the previous change was another admin's, your own
  save leaves the line reading *"Last saved just now by <the other person>"*.
  Invisible on this fixture, where there is one admin, and the old suppression
  hid the case entirely; restoring the line exposes it. One line in
  `saveDefault` — set the name from the signed-in user, or clear it — closes it.
- **The success panel on the Default tab is now undated by design.** That is
  the right trade while the audit line sits twelve pixels below it, but the two
  are only correct together: whatever fixes finding 1 should keep them in the
  same viewport, not scroll one into view and leave the other out.
- **`orgRowError?.id === org.id ? orgRowError.message : null`**
  (`PlatformSettingsPage.tsx:522`, `:598–600`) throws if a row ever arrives
  without an `id` — `undefined === undefined` passes the guard and dereferences
  a null error. Not reachable with real data (every row is selected with its
  id) and not a design finding; I hit it only by feeding the page a malformed
  row through an intercepted response. Worth `orgRowError && orgRowError.id ===
  org.id` next time that line is touched.
- Every note the third and fourth verdicts left is unchanged by this diff and
  still stands: the refusal cleared by touching any other row; the seventh
  local copy of the tile pattern awaiting a shared `ChoiceTile`; `inputStyle`'s
  1.35:1 resting border; text loading lines rather than skeletons; the
  fleet-wide breadcrumb and wordmark sizes; raw hex at the call site; and
  #19b's tab-switch reading, which one sentence in `CHECKLIST.md` would settle.
  None is this change's to carry.
